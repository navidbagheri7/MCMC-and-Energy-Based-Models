# Contributing

Keep invariant targets, integration conventions, randomness, adaptation scope
and observation/model assumptions explicit. New exact kernels require independent
mathematical oracles; approximate algorithms require visible bias/diagnostic
limitations. Retain repeated states and failures. Never tune a sampler or select
an energy checkpoint with test scores.

Run `pytest`, Ruff, public evidence validation and notebook execution. Changes to
bound scientific source require new fit directories and evaluated records; do
not relabel old evidence as coming from modified code. Keep original coursework
private and follow dataset attribution. Demos must work offline, expose original
metric sources, pass mobile/browser checks and use actual recorded states.
